# Joinery 0.7.0

Version: `0.7.0` · Godot base: `4.7.2-stable`

Changes since [0.6.2](0.6.2.md):

## A calmer editor

- **Godot's own panels on the side rail.** Scene, Inspector, FileSystem,
  Output, Audio, Animation and the Debugger open from icons on the rail, with
  Godot's own icons; there is no permanent bottom strip and no Joinery copy of
  a stock panel. The rail scrolls when it doesn't fit, with no scroll bar.
- **2D, 3D and Script as icons** in the top-right corner of the title bar.
- **The viewport toolbar starts hidden.** Show it from the Joinery menu or with
  `/toolbar`.
- **Hide or show Journeyman** from the Joinery menu, with Cmd+Option+J
  (Ctrl+Alt+J), or from its rail icon. Hiding it keeps the chat connected.
- **Files opens stacked,** the folder tree above the files, so names fit.
- **Timeline and Share redesigned.** Timeline reads as a history grouped by day;
  Share has one main action at the bottom. A second click on either rail icon
  closes the page.
- **A quieter chat.** While Journeyman works, one live line shows the latest
  step with its timer; the steps fold into "Completed in …". Console errors are
  one compact row each, with the cause behind a ›. The errors card closes once
  nothing is left to fix.
- **Reviews open by themselves** when a change is ready, never while you type.
- **Chats list:** every row keeps the same height and padding; the open chat
  is only highlighted.

## Journeyman

- **Auto-accept works for ordinary changes.** A change waits for you only when
  something needs you: a blocking review finding, a test the change broke, a
  change of direction in the brief, a Keep/Avoid line it crosses, a departure
  from your request, or one of Joinery's own files. Notes come with the kept
  change, and a reopened chat still shows them.
- **"Guessed" and "Not as you asked."** Each change says what Journeyman
  assumed and where it departed from your request; a departure holds the
  change for you.
- **"Not yet played by you."** Accepted game changes are marked until you run
  the game from the editor; the sidebar counts them and links to Play.
- **Keep and Avoid in the brief.** Pin values ("Jump height 1.2 m") and list
  what the game must not have; a change that crosses one waits for you, with
  the line it touched.
- **Feature status in `/brief`:** each feature is built, missing, broken or not
  checked, from real evidence, with when it was last checked.
- **`/cut`:** one polish list from every check, with proposed cuts and their
  reasons, written as one reviewed change. It never deletes anything.
- **Genre questions** in the new-project wizard: a few optional questions per
  starting point; answers are marked as yours, a suggested default, or skipped.
- **Rules for some files only:** "when working on `game/ai/**`" rules reach
  Journeyman when it reads or writes a matching file.
- **Asked to copy a game,** Journeyman offers your own take or a twist in the
  same genre.
- **Continue a chat** from the command line with `joinery run --chat last`; a
  resumed chat hears what changed since its last turn.
- **Search instead of reading file by file,** and fewer, larger tool calls.
  A full test game took about half the tokens of the previous release.

## Checks you can trust

- **Only what a change broke holds it.** Scene tests are compared with the
  project before the change; tests that already failed become notes.
- **Faster checks.** Results are cached, tests run in parallel, a test stuck
  after a script error is stopped within seconds, and each change starts from
  the project's import cache.
- **Nothing is thrown away.** A timeout, a crash or a stopped run keeps the
  work in review. Files refused for missing provenance are left out and the
  rest waits for review; Rule Zero is unchanged.
- **Clear errors:** no blank reasons; a usage or rate limit says when it
  resets; a hung Docker says to restart Docker Desktop.
- **Long checks report progress,** so a working request is never stopped as
  idle.
- **Accepted changes are committed** to the Timeline in full, generated Godot
  files included, and named after the change rather than the request.

## Playtests, replays and rebuilds

- **The playtest bot fights:** it aims, shoots, switches weapons, picks up
  health and ammo, takes keys before their doors and heads for the exit.
- **Replays compare what the player experiences,** with tolerance; a freshly
  recorded replay replays exactly. Journeyman can re-record one as part of a
  change.
- **Rebuilds verify Blender models and sounds by content,** and run several
  recipes at once: a 98-recipe project rebuilt in about 11 minutes instead of
  20, and a smaller one in 3.
- **Store media** frames goals and enemies instead of walls, and the trailer
  records at 1920×1080.
- **`joinery update-core`** brings an existing project's Joinery-owned game
  files up to date as one reviewed change, keeping any file you edited.

## Tools

- **Every tool tested end to end:** Godot, Blender, Material Maker, GIMP,
  Inkscape, Krita, Audacity, SuperCollider, Surge XT and music.
- **SuperCollider patches are seeded,** so a sound rebuilds byte for byte; a
  batch of sounds renders in one session, each still replayable alone.
- **Material Maker's normal and roughness maps** are no longer held to the
  palette; anti-aliased edges count as on-palette.
- **Journeyman can see its own work** with a preview of any texture or model,
  and new painted maps follow the art bible's size and density.
- **Source-only folders get a `.gdignore`,** so Godot doesn't import recipes and
  native sources.

## Setup and safety

- **An agent never approves the look.** A setup an agent runs leaves the art
  bible drafted for you to approve; a blank look is called out plainly.
- **`joinery new --answers`** takes the brief and look answers in one step.
- **The hook judges real commands,** not text that merely mentions one.
- **VR on a desktop without a headset** no longer counts as an error anywhere.

## Known limits

- Continued chats still carry their earlier conversation, so long chats cost
  more; a fresh chat with a digest per request is next.
- A few test-game findings remain open, among them a follow-up turn that
  doesn't build on its own waiting change and a transient Docker "No such
  image" at start-up.
