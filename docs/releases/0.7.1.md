# Joinery 0.7.1

Version: `0.7.1` · Godot base: `4.7.2-stable`

Changes since [0.7.0](0.7.0.md):

## Faster and leaner requests

- **A fresh session per request.** A new request in a long chat starts from a
  short digest of the project (brief, recent changes, what waits for review)
  instead of re-sending the whole chat; `joinery run --chat` keeps the old
  session for a real follow-up. On a recorded full game build this takes a
  request from about 18M tokens to 1.3–1.7M.
- **Plan, then build.** A blockout or a to-do of several steps plans first and
  builds in a fresh session; a to-do run one by one is one prompt per step.
- **Routine steps can use a lighter model** (`[agents] light_model`), for
  every agent.
- **Shorter tool results** for check reports, tool operations and blockouts,
  with the full result kept for details.
- **Checks re-check only what changed.** Art-rule measurements, Godot's import
  and scene tests are reused for files a fix didn't touch, and the final
  submit reuses the last clean precheck.
- **Godot's checks run natively on Apple Silicon** in a small new
  `joinery-godot-worker` image; the tools without a Linux arm64 build stay as
  they were. A check that runs out of time says what was running and that it
  should not be repeated; a test that crashes Godot is stopped at once.

## Journeyman shows its work

- **One live line** that replaces itself while Journeyman works, with the
  current step, its clock and the latest thought. When it's done it folds into
  "Completed in …" and opens to the whole trail.
- **Readable steps** for every agent: shell commands read as what they do
  ("Searching the code for Spawn"), never as raw commands or full paths.
- **File names are links:** a scene opens in the editor, a script in the
  script editor, an asset in Files, a native source in its own tool.
- **Test progress in words:** "Checking hose reaches flowerbed · 3 of 4 done",
  then "4 checks: 3 passed, 1 failed — frame lines up".
- **Preview · Ask to fix** on a change that is ready, before you accept it.
- **Desktop notifications** when Journeyman is done or needs you, only while
  the editor is in the background (Settings → Notifications).
- **New chat works while Journeyman works;** the busy chat keeps going.
- The chat follows new output only while you are at the bottom.

## To-do

- A new to-do opens expanded: short step titles with their details behind
  each step; edit, add, remove and reorder steps before Go; no duplicates.
- Go folds it to one line with a live light; steps are checked off as they
  are done (`todo_step`, every agent).

## Editor

- **Scenes** on the side rail and `/open <name>` find a scene through Godot's
  own Quick Open.
- **Asset categories** in the Assets view, saved in
  `design/asset_categories.toml`; every group folds.
- **Review:** Accept and Discard stay pinned on screen at any window size;
  right-drag (or middle-drag) moves the model preview.
- Nothing runs off the window at 1024×600 and larger; menus open inside the
  window. A new layouts check covers it.
- After Accept or Revert, open scenes reload only once new models and
  textures are imported; errors from an import in progress no longer reach
  the debugger.
- Godot no longer reads Joinery's own backups (`.joinery/.gdignore`).

## Fixes

- A follow-up in a chat carries on in its own change waiting for review.
- A change kept before its checks ran compiles its scripts before Accept.
- Add-on updates commit as one Timeline entry.
- Docker's passing "No such image" no longer reads as every tool missing.
- The music tool's `.gdignore` files no longer hold its changes.
- Playtest card: integer seed, room names, start and goals on the map, findings
  named inline; `--reach` is a stop on the way, not the exit.
- The store cover's title never sits over the HUD.
- New projects ignore `.DS_Store`, `Thumbs.db` and other OS files.
- `joinery match` no longer holds normal and ORM maps to the palette (#7).
- VR: the feature loads in a web export and can take an XR session started
  elsewhere (#1, by @komediruzecki); WebXR sticks, the no-headset notice,
  object picking in stereo, the desktop view after a session and the menu
  panel placement (#2–#6).
