# Joinery 0.7.3

Version: `0.7.3` · Godot base: `4.7.2-stable`

Changes since [0.7.2](0.7.2.md):

## Revert, safely

- **Revert asks first,** in place, wherever it appears: what goes back, and
  that it can be undone. Cancel has the focus; Esc answers Cancel.
- **Undo revert** on the change's card, its Review row and its Timeline
  entry, and `joinery transactions unrevert` for every agent. It puts the
  change back through the normal change path, as its own Timeline entry
  ("Restore: …"); `joinery.lock` is merged entry by entry. Files edited since
  the revert are named, with "Keep my files" or "Replace them". Older reverts
  are undone from the Timeline, LFS models included.
- Right after a revert, "Reverted … · Undo" stays above the message box for a
  few seconds.
- **No more crash after a revert.** Open scenes reloaded while Godot was
  still swapping in the re-imported model; Joinery now waits for the import
  to end, and an engine patch skips scenes closed or reloaded meanwhile.

## Journeyman

- A ready change leads with what changed ("Door model and 2 more in
  Blender"); cards share one padding; errors line up with their first line;
  the Errors card says each thing once and leads to Fix.
- Fixes: moving or floating the panel no longer ends a reply; Accept pressed
  twice sends one decision; Stop reaches a message another chat was just
  starting; a chat host crash no longer leaves another chat "working";
  a revert that ends after you leave its chat updates its card; a queued
  message no longer takes the last turn's "Completed in" line; reopened chats
  keep policy stops and refused steps; the status line wraps at 340 px;
  "Offline" fits the narrow header.
- 45 scripted UI scenarios at three widths, light and dark, in the sidebar
  and a real editor; any error printed fails them.

## Assets

- **Grouping you can find:** New category above the list, a hint while there
  are none, a ⋯ on every row and category header, a lit drop target, and
  keyboard use (arrows, Menu key or Shift+F10, F2, Delete). Deleting a
  category asks first and never deletes files.

## Fewer stalls and false alarms

- **A full disk or a stopped Docker is said plainly,** before and during a
  turn ("Docker isn't running. Start Docker Desktop, then Retry."). Docker is
  only asked about when the project's work runs in it.
- **An out-of-date recipe for an asset a change didn't touch no longer holds
  it;** it is a note in review. Everything the change touches is checked as
  before.
- Joinery's own errors never go to the debugger, and copies of scripts
  Joinery keeps can't reach Godot's language server.
- A core-file update you turned down isn't offered again until it changes
  (`joinery update-core` still offers it).
- Playtest: unreached floor is a problem only when the bot had time to get
  there; otherwise "Not reached in 1:00; a longer run would cover more".
- Krita and SuperCollider failures lead with the error, the log after it;
  Krita operations with non-ASCII text run.
- Timing adds up: a phase is never longer than the turn.

## Agents

- Read-only agents can run `git -C … diff`, checksums and `date`; git only
  ever reaches the project's own repository. A search that excludes
  `.joinery` is no longer refused.
- Small argument slips (empty content beside a patch, long notes, "centre",
  JSON sent as a string) are taken instead of refused.
- Every tool named in Joinery's instructions is spelled as each agent calls
  it.

## Under the hood

- The launcher counts only real editors, not a game left running.
- A chat host ends with its editor, even while still connecting; an engine
  patch keeps piped process ends out of later children.
- The UI scenarios run on Windows too.
