# Joinery 0.7.4

Version: `0.7.4` · Godot base: `4.7.2-stable`

Changes since [0.7.3](0.7.3.md):

## Joinery Remote

- **Your phone as a remote for Journeyman,** over your own Tailscale network
  only: read the chat, send a request, Stop, Go, Accept and Discard. Settings →
  Remote; it is off until you turn it on. See
  [ADR 0093](../adr/0093-joinery-remote.md) and the editor guide.
- **Pairing** by QR code and a one-time code, confirmed on the machine. Each
  device gets its own scopes (watch, chat, decide), can be limited to some
  projects, unpairs itself after 7, 30 or 90 days unused, and can be revoked
  at once.
- **Web Push** notifications, an optional always-on helper, and keep-awake
  while a request runs. Nothing goes out except Web Push to known push
  services.
- A decision made from a phone is recorded with the device's id in the
  Timeline. Claude's and Codex's own remote control stay off for Joinery
  sessions.
- Not yet tried against every Tailscale setup and push service; tell us what
  breaks.

## Journeyman

- **Go waits its turn:** pressed while Journeyman is still finishing, the
  to-do reads "Starting…" and starts by itself, instead of asking you to wait.
- **No "modified outside Godot" question** for files a change wrote: open
  scenes and scripts reload quietly after every kind of accept, revert and
  undo. Files with your unsaved edits are still asked about.
- **No "missing dependencies" dialog** after accepting a new model: its scene
  opens once the model is imported.
- Long chats reopen fast (300 messages in about a quarter of a second);
  older requests load as you scroll up.
- A usage limit is said once, with when it lifts and what to do. A stopped
  reply ends on a whole word with "…". "Change accepted" pairs with "Change
  discarded".
- A call the agent's own permission layer skipped for want of approval is a
  quiet step, not a refusal row. Joinery's refusals and Rule Zero stops are
  unchanged.

## Leaner sessions

- **Only Joinery's tools reach Joinery's agents.** Account-level connectors
  (mail, calendar, drive) no longer load into Claude sessions; Codex sessions
  run without the user's own MCP servers, apps and its image generator.
- Routine to-do steps run at medium effort at most; planning, art, models,
  sound, debugging and retries keep the effort you chose. The timing line
  lists every effort a turn used.
- Joinery checks steps off itself and gives each step the tools it needs, so
  agents spend fewer calls on bookkeeping. Joinery's core tools load up front.
- A whole read of a long file is turned down with its length and how to read
  less; `find_recipe` sums up a recipe instead of its full script; project
  search groups matches by file and returns fewer; long results page by line.
- Common slips are taken instead of failing: a Godot call without the project
  path, a misnamed file argument, `name` for `tool`, `paint_map` past 32
  operations (painted in batches).
- Agents are told the palette and albedo rules and what a Blender GLB export
  holds, and to run one plain command at a time.

## Settings

- Remote: which projects each device may use, and how long devices last.

## Under the hood

- A local engine build runs from a Joinery.app wrapper on macOS, so it shows
  as Joinery in the Dock.
- Palette failures again show the measured and allowed share.

Joinery does not use image, 3D, music or voice generators. Every asset is made
in a real tool, kept as an editable source file, and has a recipe that rebuilds
it. Games made with Joinery are plain Godot projects and open in stock Godot.
