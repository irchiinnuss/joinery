# Joinery 0.7.2

Version: `0.7.2` · Godot base: `4.7.2-stable`

Changes since [0.7.1](0.7.1.md):

## Faster steps

- **Reads run side by side.** Godot reads of one change run at once beside
  other calls (`read_tool`, read-only, every agent); writes still run alone.
- **Quicker checks.** Godot's import and tests run on a copy of the stage
  inside their worker, one copy per change. Deleting a file, or touching one
  Godot never imports, runs no import. A precheck under load went from about
  5 minutes to about 1.
- **A step is done only when its assets are.** A to-do step ends with the
  asset gate over what it touched. A model edit that drops a map replaces its
  recipe, and one that fails halfway is undone instead of leaving a broken
  asset for the next step.

## Chats

- **Another chat no longer waits.** A message sent from another chat while
  Journeyman works starts at once as that chat's own turn, when an agent is
  free (`[agents] parallel`), with its own steps, Stop and review. It only
  queues when every agent is busy.
- A click in the Chats list always opens the chat or says why not.
- Stop in one chat leaves another chat's work running.

## Journeyman sidebar

- **Clear endings.** A failed request ends with the error mark and "Failed
  after…", a stopped one with "Stopped"; a refused call says why ("Not run:
  …") and the request reads "Done in 0:12, 1 step not run".
- **Errors and stops:** a provider error shows once, as an error, with
  Retry. A Rule Zero stop is a notice of its own that says what was attempted,
  with a way on.
- **Keys:** Esc stops a running reply; Tab moves focus.
- "Thinking…" gives way to "Writing the reply…"; the timer shows after one
  second; short turns read "under 1 s".
- Replies render headings, lists, italics and bold; code is in mono and
  scrolls sideways instead of wrapping.
- Once you accept or discard, nothing still asks for that review.
- The to-do card's Go and the playtest card's Show all stay in sight; the
  header lines up with the conversation on wide sidebars.
- A console error is offered in one place, the Errors card, as Fix.

## Playtester

- **Only when asked:** `/playtest`, its card, or a request that asks for a
  playtest. Settings → Advanced → Agents → Playtester
  (`[agents] playtester = false`) turns it off for the project.
- The card says what ran and what it means, in plain words.
- The map is a real top-down picture of the level; "not reached" marks only
  places a player can stand. The bot faces things before using them and jumps
  up steps.
- Godot's exit lines ("leaked at exit" and the like) are never findings.

## Console errors

- Errors from Godot's import cache being briefly out of date after a change
  are held until the import ends, read again, and dropped when they cleared.
  A file that still fails is imported once more, then reported as one line,
  "leaf_rake.glb didn't import".

## Editor

- **Quiet when idle.** Hidden loading animations kept the editor redrawing
  about 110 times a second; it now draws nothing while idle, and its CPU use
  drops from about 38% to 12%.
- **macOS notifications show Joinery.** A small helper app sends them with
  Joinery's icon; macOS asks once to allow them. Without it, they go out as
  before.

## Under the hood

- A UI test harness drives the real sidebar with a scripted agent: 26
  scenarios at three widths, light and dark, in the sidebar and a real editor
  (`tests/godot/run_ui_scenarios.py`).
- Background tasks are kept until they end, and their failures logged.
